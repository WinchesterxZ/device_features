# Device Information Display App (Flutter)

This project demonstrates how to retrieve and display device model and operating system version information using Flutter.

## Task Description

The goal of this task is to create a simple Flutter application that displays the device's model name and OS version in the center of the screen.

## Requirements

*   **Title:** Show your device model and OS version
*   **Description:** Design a page and add in the center of it text that displays the device model name and its operating system version.

## Project Overview

This Flutter app utilizes the `device_info_plus` package to retrieve device information.  The UI consists of a single centered `Text` widget displaying the combined model name and OS version.

## Dependencies

*   `device_info_plus`: Used for retrieving device information. Add this to your `pubspec.yaml` file.
