# Google Maps Integration in Flutter

This project integrates Google Maps into a Flutter application and places a marker on Cairo, Egypt.

## Task Description

The app displays a Google Map centered on Cairo, Egypt, with a marker placed on the Cairo Governorate.

## Requirements

*   **Requirement 1:** Add Google Maps to your application. Create a page with the title "Google Map" in the AppBar and display the map on the screen.
*   **Requirement 2:** Add a marker on Cairo, Egypt. Place a red Google Maps marker on the Cairo Governorate.

## Project Overview

This Flutter app uses the `google_maps_flutter` package to display the map and add the marker.

## Getting Started

1.  **Clone the repository (if applicable).**

2.  **Install Dependencies:**

    ```bash
    flutter pub get
    ```

3.  **Obtain a Google Maps API Key:** You'll need an API key to use Google Maps.  Follow the instructions in the `google_maps_flutter` package documentation to create one and enable the Maps SDK for Android and iOS.  Add the API key to your `AndroidManifest.xml` (Android) and `Info.plist` (iOS) files as described in the documentation.

4.  **Run the app:**

    ```bash
    flutter run
    ```

## Dependencies

*   `google_maps_flutter`: Used for integrating Google Maps. Add this to your `pubspec.yaml` file.
