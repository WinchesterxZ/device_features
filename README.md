# Audio Recording and Playback App (Flutter)

This project creates a Flutter app that allows users to record audio and play it back.

## Task Description

The app features a "Record Audio" button to start recording and a "Play Audio" button (which appears after recording) to play the recorded audio.

## Requirements

*   **Requirement 1:** Add the first button on your screen. The button should be named "Record Audio." When pressed, it starts recording the user's voice.
*   **Requirement 2:** Add the second button. This button only appears after audio has been recorded. It should be named "Play Audio." When clicked, it plays the recorded audio.

## Project Overview

This Flutter app uses the `record` and `just_audio` packages (or similar audio recording/playback packages) to implement the recording and playback functionality.

## Dependencies

*   `record`: Used for audio recording. Add this to your `pubspec.yaml` file.
*   `just_audio`: Used for audio playback. Add this to your `pubspec.yaml` file.  (Or another suitable audio playback package).
